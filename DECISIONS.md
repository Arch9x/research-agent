## 2026-08-19 — Референсы (нулевое задание)

**Что смотрел:** `refs/go-deep-research` (wtlow003) и `refs/laconic` (smhanov).

### Как они устроены внутри
- Оба — это **агентский цикл**: LLM решает, что делать, программа выполняет инструменты (поиск/чтение), результат возвращается в контекст, цикл повторяется.
- **go-deep-research**: 4 последовательных воркфлоу (уточнение → бриф → исследование → отчёт). Модель сама решает через **tool calling** (`search_tool`, `reflection_tool`). Контекст **накапливается** (история растёт), страницы сжимаются в выжимки.
- **laconic**: роль-модели (Planner → Synthesizer → Finalizer). Планировщик решает **текстом** (search/answer). Контекст **сжимается** в поле `Knowledge` вместо накопления.

### Чем отличаются
| | go-deep-research | laconic |
|---|---|---|
| Управление | tool calling (модель просит вызвать инструмент) | planner решает текстом |
| Контекст | накапливает выжимки | перезаписывает краткой сводкой |
| Роли | один цикл + 2 инструмента | 4 роли моделей |

### Что беру себе
- **Tool calling** — модель сама решает, что искать (соответствует ТЗ и SDK openai-go).
- **Разделение ролей / субагенты** — по ТЗ обязательны НАСТОЯЩИЕ несколько агентов (в референсах их нет, там этапы/роли).
- **Сжатие контекста** — не тащить всё накопленное; передавать только нужное (бриф → выжимки → отчёт).
- **Жёсткие лимиты в коде** (поисков, страниц, времени) — а не только в промпте.
- **Честный учёт** — вызовы модели стоят денег.

### Что отвергаю и почему
- **Безграничное накопление контекста** (go-deep-research) — переполненный контекст тупеет и дорожает.
- **Лимиты только в тексте промпта** (go-deep-research) — модель может не послушаться.
- **Отказ от tool calling** (laconic) — решение текстом менее гибко, для ТЗ подходит tool calling.

## 2026-08-30 — Реализация

**Что сделано:** собран весь агент (каркас → уточнение → исследование → отчёт → деплой).

### Решения
- **Поиск — Exa.** Обсуждали ранее, зафиксировал: `internal/tools/search.go` (API `api.exa.ai/search`, `contents.text=true`). Ключ в `.env`.
- **Модель — та же, что у меня (deepseek-v4-flash:0731 через ollama.com/v1).** OpenAI-совместимый endpoint, работает с официальным SDK `openai-go`. Ключ — из `auth.json` opencode.
- **SDK — официальный `github.com/openai/openai-go/v3`** (по ТЗ), а не community `sashabaranov/go-openai`, как в референсе go-deep-research.
- **Reasoning-модель: `thinking: {"type":"disabled"}`.** Модель — reasoning-модель: без отключения весь бюджет токенов уходит в `reasoning`, а `content` пустой. Добавляю через `option.WithJSONSet` в каждый запрос.
- **3 субагента** (по ТЗ — настоящие, не этапы): Clarifier (вопросы), Researcher (tool calling + сеть), Reporter (отчёт). Каждый — отдельный вызов LLM со своим контекстом.
- **Reporter не может выдумать ссылку** — два уровня защиты: (1) у него нет инструментов и сети, видит только находки «факт+URL»; (2) программная проверка `verifyLinks` вырезает любую ссылку, которой нет в находках.
- **Находки — через инструмент `add_finding_tool`.** Researcher записывает «факт + URL» в сессию; Reporter пишет отчёт только из них. (Первый прогон дал пустой отчёт — Researcher искал, но не сохранял находки.)
- **Уточнение — один раунд.** Сначала сделал цикл до 3 раундов — Clarifier повторял вопросы. По ТЗ нужен один раунд 2–4 вопросов.
- **Лента — SSE.** `internal/events` — хаб, рассылает события всем подключённым браузерам.
- **Лимиты — в коде** (`internal/research/session.go`): поиски, страницы, время, минимум источников/доменов. «Тощий отчёт» — Researcher обязан копать или честно сказать.
- **Хранение — файлы JSON** в `reports/` (без БД, по ТЗ).
- **Деплой — Render** из GitHub-репозитория, ключи в env.

### Провалы недели (честно)
- **Пустой отчёт:** Researcher искал и читал, но не сохранял находки — Reporter писал «не удалось собрать ни одного источника». Исправлено добавлением `add_finding_tool`.
- **Повторные вопросы:** Clarifier во втором раунде задавал те же вопросы — убрал цикл, оставил один раунд.
- **Reasoning съедал ответ:** модель возвращала пустой `content` при малом `max_tokens` — отключил thinking.
