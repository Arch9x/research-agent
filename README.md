# Research Agent

Мини-Perplexity: веб-приложение, которое исследует любой вопрос по интернету и собирает честный отчёт со ссылками.

## Как это работает

1. Пользователь вводит тему в браузере.
2. **Clarifier** задаёт 2–4 умных уточняющих вопроса из темы (не анкетные).
3. После ответов **Lead Researcher** разбивает бриф на 3–5 линий (под-вопросов) и запускает **субагентов параллельно** — каждый исследует свою линию: ищет через Exa, читает страницы, записывает находки «факт + URL». Всё это видно вживую в ленте событий (SSE).
4. Если по дороге Lead Researcher упирается в развилку — он задаёт вопрос до запуска линий.
5. Субагенты возвращают главному только саммари + источники; главный синтезирует их в общую картину.
6. **Reporter** пишет отчёт: вывод первой строкой, каждое утверждение со ссылкой, явные противоречия, честный раздел «Что выяснить не удалось».
7. Отчёты сохраняются, к старым можно вернуться.

## Архитектура: 4 субагента

| Субагент | Что делает | Что видит | Инструменты |
|---|---|---|---|
| **Clarifier** | задаёт 2–4 уточняющих вопроса | только тему + историю уточнений | нет |
| **Planner** | разбивает бриф на 3–5 линий | бриф | нет |
| **Lead Researcher** | планирует, запускает линии параллельно, синтезирует | бриф + саммари линий | `ask_user_tool`, `finish_tool` |
| **Line Researcher** (×3–5) | ищет, читает, записывает находки по своей линии | только свою линию + результаты своих поисков | `search_tool`, `read_tool`, `add_finding_tool`, `finish_tool` |
| **Reporter** | пишет отчёт | **только** находки «факт + URL» + синтез | нет |

**Почему Reporter не может выдумать ссылку:** у него нет инструментов и доступа к сети — он получает только список находок, собранных субагентами. Плюс программная проверка `verifyLinks`: любая ссылка в отчёте, которой нет в находках, вырезается.

## Лимиты (жёсткие, в коде)

- максимум поисков (`MAX_SEARCHES`, по умолчанию 15) — общий пул на все линии
- максимум прочитанных страниц (`MAX_PAGES_READ`, по умолчанию 20) — общий пул на все линии
- общее время исследования (`MAX_RESEARCH_TIME_SECONDS`, по умолчанию 300)
- «тощий отчёт»: если собрано меньше `MIN_SOURCES` источников или `MIN_DOMAINS` доменов — Researcher обязан копать дальше или честно написать, что тема не раскрыта
- таймауты на каждый HTTP-запрос; одна мёртвая ссылка не роняет прогон

## Запуск

Требуется Go 1.25+.

```bash
cp .env.example .env
# впиши ключи:
#   OPENAI_API_KEY  — ключ OpenAI-совместимого провайдера
#   OPENAI_BASE_URL — например https://ollama.com/v1
#   MODEL           — например deepseek-v4-flash:0731
#   EXA_API_KEY     — ключ Exa (https://exa.ai)

go run ./cmd/server
```

Открой http://localhost:8080

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `8080` | порт сервера |
| `OPENAI_API_KEY` | — | ключ модели (обязательно) |
| `OPENAI_BASE_URL` | `https://ollama.com/v1` | OpenAI-совместимый endpoint |
| `MODEL` | `deepseek-v4-flash:0731` | модель |
| `EXA_API_KEY` | — | ключ Exa (обязательно) |
| `EXA_ENDPOINT` | `https://api.exa.ai/search` | endpoint Exa |
| `EXA_NUM_RESULTS` | `8` | результатов на поиск |
| `MAX_SEARCHES` | `15` | лимит поисков (общий пул на все линии) |
| `MAX_PAGES_READ` | `20` | лимит прочитанных страниц (общий пул на все линии) |
| `MAX_RESEARCH_TIME_SECONDS` | `300` | лимит времени исследования |
| `MIN_SOURCES` | `3` | минимум источников для отчёта |
| `MIN_DOMAINS` | `2` | минимум доменов для отчёта |
| `REPORTS_DIR` | `reports` | папка сохранения отчётов |

## Структура

```
main.go                — HTTP-сервер, SSE, оркестрация
internal/config/       — конфигурация из env
internal/llm/          — клиент openai-go
internal/agents/       — clarifier.go, planner.go, researcher.go, line.go, reporter.go
internal/tools/        — search.go (Exa + чтение страниц)
internal/events/       — лента событий (SSE)
internal/research/     — сессия исследования, лимиты, находки
internal/store/        — сохранение/список отчётов
```
